# Tom The AI

Welcome to the official repository for **Tom The AI**, hosted by **math12393**.

## Project Goal
Tom is a completely free, browser-based AI interface. This project is designed to be lightweight, open-source, and accessible to everyone without any subscription fees.

## Quick Start
1. Navigate to the [Codeberg Pages link](https://math12393.codeberg.page/TOM-The-AI-Wen/) (if enabled).
2. Or, download `index.html` and open it in any browser.
